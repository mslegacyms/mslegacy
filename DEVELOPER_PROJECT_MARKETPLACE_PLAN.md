# MS Legacy — Developer & Project Discovery Marketplace Plan

This document details the vision, compliance frameworks, verification matrices, and CRM structures for the Karnataka Developer & Project Discovery Marketplace.

---

## 1. Marketplace Vision
An institutional-grade, data-rich registry of real estate promoters and layout/apartment projects in Karnataka. The marketplace serves as an advisory portal helping HNI and NRI buyers identify verified assets, compare configurations, and request legal due diligence audits.

---

## 2. Customer Journey
1.  **Discovery**: Browse all major developers or filter by project type (plotted, apartment, villa, farmland), corridor, or status.
2.  **Sifting**: View verification ratings (RERA status, Developer Confirmed, public record status).
3.  **Comparison**: Compare layout dimensions, prices, towers, and amenities for up to 3 projects side-by-side.
4.  **Engagement**: Request advisory analysis or title search audit clearances from the MS Legacy legal desk.

---

## 3. Product Categories & Statuses

### Categories:
*   **Apartment Developments**: High-rise residential complexes.
*   **Plotted Developments**: Gated layout plots (e.g., BDA sites, private layouts).
*   **Villa Developments**: Detached custom residences.
*   **Farmlands / Managed Land**: Managed agricultural plots.

### Verification States:
*   `mslegacy_verified`: Layout physically inspected, mother deeds audited, boundary coordinates validated.
*   `rera_verified`: Verified matching active records in the Karnataka RERA registry.
*   `developer_confirmed`: Data supplied directly by developer marketing desks.
*   `public_info`: Sourced from public marketing brochures; verification pending.

---

## 4. Compliance & Intellectual Property Policy
*   **No Logos**: No third-party logos will be hosted unless permission is verified. A placeholder "Logo Pending Permission" badge will be displayed instead.
*   **No RERA Claims**: Never assert RERA approval unless the active registration number is matched with the state database.
*   **Required Disclaimer**: Every single developer/project view must render the legal advisory waiver.
