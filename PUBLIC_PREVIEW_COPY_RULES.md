# Public Preview Copy Rules

This document defines standard labels and copy blocks for public project listings on the MS Legacy platform.

---

## 1. Wording Specifications

### If "Public Information · Verification Pending"
*   **Card Badge Label**: `Public Information · Verification Pending`
*   **Dossier Banner Copy**:
    > "This project is listed for discovery and advisory reference based on publicly available information. Key details must be verified with the developer, Karnataka RERA, and independent legal advisors."

---

### If "RERA Record Matched"
*   **Card Badge Label**: `RERA Record Matched`
*   **Dossier Banner Copy**:
    > "RERA record details have been matched against publicly available registration information. Pricing, availability, possession, approvals, and documents must still be verified before any decision."

---

### If "Needs Legal Review"
*   **Visibility**: Hidden on all public routes. Rendered only in CRM internal paths with a warning header.

---

### If "Keep Internal Only"
*   **Visibility**: Gated. Hidden on all public routes.
