# Layout Approval Authority Source Register

This register documents the official databases, regulatory authorities, and verification paths that govern land layout approvals in Karnataka.

---

## 2. Manual Verification Notes
*   **lake Buffers**: Check NGT 30-meter buffers directly on-site against the survey sketch.
*   **Approach Road**: Verify that the road width is documented on public maps before acquisition.
