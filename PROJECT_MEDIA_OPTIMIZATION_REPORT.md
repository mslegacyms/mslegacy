# Project Media Optimization Report

This report tracks conversion, compression, and scaling parameters for uploaded project media.

---

## 1. Optimization Standards
*   **Hero Images**: 1600px wide, converted to `.webp` format.
*   **Card Images**: 900px wide, converted to `.webp` format.
*   **Thumbnails**: 500px wide, converted to `.webp` format.
*   **Format Policy**: Convert all JPEG/PNG media to high-density, low-latency `.webp` files.
*   **Videos**: Store external stream URLs in `video-url.txt` files; load optimized web poster previews to avoid loading heavy local payloads.
