# Internal Project Review Checklist

Verify each of the following checklist items before toggling any project layout to `published` in the CRM admin dashboard.

---

## 1. Compliance Checklist

- [ ] **Name Match**: Project name matches RERA certificate registration name.
- [ ] **Developer Match**: Assigned promoter name matches official legal entities.
- [ ] **Locality Bounds**: Location corridor mapped to correct regions.
- [ ] **RERA Validation**: Karnataka RERA certificate verified and active.
- [ ] **Disclaimers Active**: Default advisory disclaimers visible at the page bottom.
- [ ] **Price Sifting**: Budget range clearly labeled as estimated value.
- [ ] **Logo Permissions**: Logo matrix checked. If pending, confirm text-only placeholder is active.
- [ ] **Brochure Clearances**: Confirm brochures/floor plans are hidden or marked pending permission unless written releases are logged.
- [ ] **Zero ROI Vocabulary**: Descriptions scanned for guaranteed returns or token-appreciation language.
- [ ] **Exposed Data**: Verify no developer phone numbers, private emails, or pricing spreadsheets are rendered publicly.
- [ ] **Founder Sign-Off**: Received final approval token from the chief administrator.
