# MS Legacy — CRM Developer Data Entry Checklist

Admin checklist before inserting or publishing a promoter/project profile in the CRM dashboard.

---

## 1. Developer Level Entries
- [ ] **Slug Validation**: Confirm slug contains only lowercase characters and hyphens (e.g. `prestige-group`).
- [ ] **Logo Permission Flag**: Verify logo status matches the permission tracker (`pending_permission` by default).
- [ ] **Legal Name**: Double-check legal registration name matches MCA records.

---

## 2. Project Level Entries
- [ ] **Developer Assignment**: Associate the layout with a valid developer record.
- [ ] **Project Type**: Select the correct category (apartment, plotted, villa, farmland).
- [ ] **RERA Number Verification**: Double-check registration strings against the Karnataka RERA portal.
- [ ] **RERA Status**: Select appropriate state (`approved`, `not_applicable`, `under_process`).
- [ ] **Pricing Verification**: Mark pricing brackets as verified or estimate.
- [ ] **Floor Plan Permission**: Ensure floor plans are hidden unless written clearance is logged.
- [ ] **Disclaimer Visibility**: Ensure the default advisory disclaimers are mapped.
- [ ] **Public Visibility**: Set visibility status to `draft` (default) until legal cleared.
- [ ] **No Risky Vocabulary**: Scan descriptions to ensure terms like "fixed returns" or "guaranteed appreciation" are **absent**.
