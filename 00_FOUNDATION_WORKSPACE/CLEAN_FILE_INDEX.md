## Resolution of Duplicates

*   **Sitemap Duplicate**: `website structer/website structer.docx` and `MS legacy Group/website structer.docx` are identical. Both were migrated into `01_clean_markdown` under their respective folders to preserve structure. For actual website layout coding, only `MS legacy Group/website structer.md` should be referenced as the layout master script.
*   **Links Directory Duplicate**: `website contant/property documentation and links.docx` and `website contant/important web sites.docx` are identical. Both were migrated into `01_clean_markdown`. They will be consolidated into a single resources hub page layout in `03_website_content`.
*   **Investment Draft**: `INVESTMENT OPPORTUNITIES done.docx` is an earlier, shorter draft of the copy in `INVESTMENT OPPORTUNITIES PAGE done.docx`. Both files were migrated to markdown, but developers should strictly ignore the shorter "done" file and use `INVESTMENT OPPORTUNITIES PAGE done.md` as the source copy for the frontend.
