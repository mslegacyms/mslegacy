# Real Project Data Collection Priority List

This document establishes the sourcing milestones and mandatory parameters required for catalog listings before public marketplace indexing is authorized.

---

## 1. Sourcing Parameters by Tier

### P1 — Sourcing Minimums (Mandatory for Public Listing)
*   **Developer Identity**: Legal corporate promoter name.
*   **Project Name**: Official municipal or RERA registered project layout name.
*   **Asset Class**: Select matching type (apartment, plotted, villa, farmland).
*   **Location Coordinates**: Locality name, city, and corridor boundaries.
*   **RERA Status Check**: RERA certificate ID and active approval state.
*   **Construction status**: Ongoing, completed, or upcoming.
*   **Logo Clearance**: Status flag logged in the permission matrix (defaults to `pending_permission`).
*   **Legal Disclaimers**: Mapped to show waiver links.

---

### P2 — Highly Recommended (To Complete Within 7 Days of Import)
*   **Unit Configurations Grid**: BHK configuration, built-up areas (SBA), or plot dimensions.
*   **Price Brackets**: Minimum starting value indicator (marked as estimate).
*   **Possession Timeline**: Possession target date matching RERA filings.
*   **Amenities Matrix**: Checklist of onsite amenities (clubhouse, security, etc.).
*   **Brochure Clearance**: Consent to host project brochure files.
*   **Floor Plan Clearance**: Consent to host unit layout blueprints.
*   **Authorized POC**: Email, phone, and name of developer's channel POC.
*   **Google Maps Siting**: Verified GPS location link.

---

### P3 — Premium Enhancements (Added Post-Verification)
*   **Siting Media**: Drone surveys, master layout plans, and site photos.
*   **PMC Construction Logs**: Periodic updates on road paving or civil works progress.
*   **Legal Title Dossier**: Traced 30-year mother deed brief and municipal sanctions logs.
*   **MS Legacy Advisor Vetting Notes**: Advisory highlights from our legal desk.
