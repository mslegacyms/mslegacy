# MS Legacy — Developer & Project Verification SOP

This Standard Operating Procedure defines the verification checklist and workflows required before publishing layout or promoter data to the public marketplace.

---

## 1. Ten-Step Sourcing & Verification Workflow

### Step 1: Promoter Identification
Verify that the developer or promoter represents a legally registered corporate entity in India.

### Step 2: Official Website Review
Inspect official digital assets to list established years, headquarters location, and contact POCs.

### Step 3: Karnataka RERA Registry Verification
*   Query the project name or developer name on the [Karnataka RERA Portal](https://rera.karnataka.gov.in).
*   Verify that the RERA registration certificate matches the active phase or tower number.

### Step 4: Name Matching
Check name strings against the developer's registry database to prevent duplicate entries or mislabeling.

### Step 5: Location Corridor & Micro-market Confirmation
Cross-check district boundaries and local connectivity to map assets inside correct corridors.

### Step 6: RERA Status Check
Verify status states:
*   *Approved*: Active certificate visible on state records.
*   *Under Process*: Registered but certificate pending.
*   *Not Applicable*: Farm layouts or plotted layouts under 500 sq meters or 8 units.

### Step 7: Brochure & Floor Plan Permission checks
Audit that brochure PDFs and architectural layout plans have active marketing clearance releases from the developer.

### Step 8: Price Bracket Sifting
Log starting price indicators. Mark as estimated values unless verified by developers.

### Step 9: MS Legacy Internal Review
Submit files to the legal desk to complete mutational history checks.

### Step 10: Visibility Publishing
Mark project visibility as `draft` or `published` based on review.

## 2. Verification Levels Table

| Level | Definition | Mandatory Proof |
| :--- | :--- | :--- |
| **Pending Verification** |Sourced from public databases but not audited | Default initial state |
| **Public Information** | Sourced from developer websites; no separate audits done | Link to developer project page |
| **Developer Confirmed** | Confirmed directly by developer marketing desks | Sourcing agreement copy |
| **RERA Verified** | Matches active RERA certificate records | RERA Certificate PDF |
| **MS Legacy Verified** | Gated community audited by MS Legacy | Signed title search dossier |
