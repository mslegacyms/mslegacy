# Project Showroom Client Demo Script

A 5-minute documentation-first walkthrough script for client demos and advisory presentations.

---

## 1. Demo Flow Outline

### Minute 1: The Curated Catalog
*   **Action**: Open **[/projects](file:///projects)**.
*   **Dialogue**: *"We start at the MS Legacy Showroom. Unlike general aggregators, we list a curated catalog. You can filter by RERA status, asset class (apartments, plots, villas), and verification tier."*

### Minute 2: Layout Profiling
*   **Action**: Select **Prestige Lakeside Habitat**.
*   **Dialogue**: *"Each listing displays RERA record verification and warnings detailing what land documents must still be audited before title registration."*

### Minute 3: Comparison Matrix
*   **Action**: Click **Compare Project** and view **[/project-compare](file:///project-compare)**.
*   **Dialogue**: *"You can select multiple layouts side-by-side to contrast land areas, starting prices, and possession timelines."*

### Minute 4: Planning Assumptions
*   **Action**: Open **[/calculators](file:///calculators)**.
*   **Dialogue**: *"Our planning calculators show stamp duty estimates, NRI tax metrics, and affordability limits. All inputs are editable planning assumptions rather than fixed rules."*

### Minute 5: Gated Enquiry
*   **Action**: Scroll to the **Advisory Enquiry Form** and submit a request.
*   **Dialogue**: *"To lock in a consultation or initiate a 30-year title search, submit your interest here. All communications remain confidential under our privacy protocols."*
