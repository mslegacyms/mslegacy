# Official Project Media Optimization Report

This report outlines target widths, conversion protocols, and compression details for catalog images.

---

## 1. Quality Standards
*   **Hero Image**: 1600px wide, `.webp` format.
*   **Card Image**: 900px wide, `.webp` format.
*   **Gallery Image**: 1400px wide, `.webp` format.
*   **Sourcing logic**: Download original layout renders from promoter sites, downscale, and convert to `.webp` to preserve layout speeds.
*   **Status**: Awaiting developer asset uploads. Premium vector placeholders render dynamically.
